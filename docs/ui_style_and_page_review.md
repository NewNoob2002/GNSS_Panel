# 页面结构、视觉规则与验证

共享应用源码位于本仓库 `App/` 与 `Frameworks/`（本仓库为唯一来源）。共享框架、核心服务与 UI 的构建边界见 `App/ARCHITECTURE.md`。本次统一了 SaveConfig 倒计时/等待图标与 Startup 快速重按修复。

## 当前职责与入口

```text
待机 Startup → 初始化 SystemLoading → 首页 Dialplate
                                      ├─ 工作配置 WorkSettings
                                      ├─ 记录管理 RecordConfig
                                      ├─ 设备信息 SystemInfos
                                      ├─ 系统 SystemDash
                                      │    ├─ 语言
                                      │    ├─ Wi-Fi（按产品能力）
                                      │    ├─ 电源 → 确认 → SaveConfig
                                      │    └─ 返回
                                      └─ 卫星区 → 卫星详情 StarMap（按产品能力）
```

| 页面 | 职责与本轮调整 |
| --- | --- |
| Dialplate | 快速查看工作状态并进入常用任务。四个入口以原 Device Info 三横线为视觉基准，统一原创白色 16×16 alpha 图标：工作参数、记录、信息列表、系统齿轮。移除底部焦点文字，按钮恢复 56×32；卫星区保持纯数值。录制中以红框提示，不伪装为直接停止按钮。右侧两张状态卡：电台卡为天线，开启时两侧画收发波形（TX 外扩、RX 内收）；模式卡为 RTK 设备造型（基准站=三脚架接收机，移动站=对中杆接收机加手簿），基准站天线罩上方播发弧依次外扩，移动站信号点落入天线罩后杆尖扩散测点涟漪。动效均画在图标外侧，仅工作模式有效时运行，按 50 ms 步进重绘。 |
| WorkSettings | 选择电台移动站、电台基站、网络基站预设，再调整电台参数并显式应用。预设切换不直接下发命令。网络基站隐藏电台字段。 |
| RecordConfig | 显示记录状态、剩余空间、格式/间隔及启停。默认聚焦主操作，开始与停止都是单击（双击同样有效）；记录中和请求等待时锁定参数。XBase 显示固定参数，不再展示禁用的调整箭头。 |
| SystemInfos | 恢复全屏只读诊断，保留工作、定位、网络、电池、存储、系统六项。每次进入默认聚焦根页面，滚轮/方向键翻阅信息项，根页面或信息项点击即返回；不保留上次查看项、不显示新增浏览提示。 |
| SystemDash | 合并原系统菜单和设置子页，同屏提供语言、Wi-Fi、电源和返回。旧 SystemSettings 代码与路由已删除，无兼容别名。 |
| StarMap | 各星座数量详情，可见标题为 Satellites/Спутники，内部路由保留。 |
| Startup | 待机信息、电池、完整长按 2 s 后请求平台开机；HC32 带屏产品仅接受此请求（软件复位自动开机除外）。无卡片：左侧大号电量数字、电池条与 FW/HW 一行，右侧透明长按区为进度环与电源图标，下方“开始/长按 2 秒”同一行。 |
| SystemLoading | 品牌和初始化阶段：按平台真实检查结果推进（每步耗时不固定，最短显示 300 ms，超过 1 s 显示等待秒数），失败标红不中断启动，完成时有失败显示警告。HC32 第 5 步等待主控通信最长 30 s。 |
| SaveConfig | 用户关机准备与平台关机原因。进入前的电源确认窗：长按 Power 2 s 进度满 100% 确认，短按或提前松开关闭窗口；平台关机不可取消。无卡片：左侧进度环（关机红、重启橙）内含电源图标与百分比，右侧竖直居中的动作、原因、提示三行文字。 |

页面按任务划分，工作、记录与只读信息继续独立；整合了价值较低的系统设置中间层，工作页焦点从原来 8 个减少为 5 个（网络基站 3 个），记录页从 6 个减少为 4 个（固定参数或记录中仅主操作与返回）。

## 工作预设和应用反馈

- 进入工作页时从设备快照读取预设、协议与信道，默认聚焦预设；选择在三种预设之间循环，协议/信道各自单击循环。
- 点击 Apply 才发送，提交动作也仅在聚焦 Apply 时有效。CUSTOM 信道用于电台预设时留页提示，网络基站不受此限制。
- 页面保持打开，反馈区分等待主控、请求已接收、拒绝、15 秒超时；等待期间不允许覆盖同类请求，但始终可以返回。
- 记录操作复用相同的反馈规则。开始与停止都是单击（双击/Commit 同样有效），等待主控确认时按钮锁定，重复提交不会覆盖正在等待的请求。
- 状态栏 SD 图标跟随主控回报的实际录制状态（HC32 `StatusBridge` 读 `systemInfo.host.record`）：变化时先滑出状态栏、在栏外换色再滑回，录制中蓝色闪烁，未录制为静止白色；主控确认前不变。
- 返回页面不取消已经发送的主控请求，超时也不清除平台请求；迟到的确认会更新为已接收。
- HC32 `DeviceBridge` 将 `work_pending`、`record_op || record_settings_pending` 发布为共享快照的等待状态。协议确认的是主控已读走请求，**不是物理操作已经完成**，因此文案使用 Request received，不显示 Apply succeeded。
- 模拟后端可同步接受并发布状态；真实平台可异步报告，页面兼容两种情况。等待定时器在离页及卸载时清理；语言更新不重建其他缓存页的焦点组。

## 视觉与动画

通用颜色集中在 `App/Utils/PageStyle.h`。

| 语义 | 颜色 |
| --- | --- |
| 背景 / 面板 / 卡片 | `#101214` / `#202428` / `#181C20` |
| 边线 / 主文字 / 次文字 | `#414A52` / `#F2F4F5` / `#A4ADB5` |
| 焦点边框 / 焦点底色 / 按压底色 | `#FF931E` / `#34302A` / `#3A424A` |
| 正常、移动站、RX / 基准站、TX、连接 | `#28C76F` / `#3498DB` |
| 危险、失败 / 进度高亮 | `#D03C3B` / `#F6D062` |

星座分类色条、Logo、过温横幅继续使用各自的语义色。圆角沿用 8–12 px，焦点立即切换橙框，按压尺寸保留动画。Dialplate 已移除重复的边框颜色过渡，连续 100 次快速正反向切焦点回归检查只有当前控件显示橙框。

工作、记录、系统设置改为左侧图形主卡和右侧参数/操作卡，加入原生 16/32 px 图标、渐变、网络连接图形与状态点。控件每隔 40 ms 依次从下方 6 px 上移进入（只做位移、不做透明度，避免与页面滑动叠加的逐控件混合开销），数值变化时短淡入；只有主控等待或记录进行时状态点持续呼吸，离页和销毁时停止。正常状态不增加操作说明文字，错误、等待、确认等业务反馈保留。

`Vendor/Linux/tools/generate_ui_icons.py` 保存原创矢量路径并用已有 ImageMagick 生成 26 个原生尺寸 alpha 资源（16/32 px 按各自网格单独设计）。渲染先 8 倍超采样再按整数倍盒式平均得到真实像素覆盖率（不用会产生振铃灰边的 Lanczos 缩放），2 单位描边、方头斜接，使横竖线落在整像素上；覆盖率再经过渡带收紧（45° 小块拼成的卫星图标用更窄的过渡带）。自检包含像素数量、亮度、首页图标墨量，以及半透明像素不超过有效像素一半的清晰度检查。未引入外部图标下载依赖，固件运行时不缩放图标。

状态栏分左右两组按内容紧凑排列：左为卫星图标与卫星数、定位箭头与定位状态，中为时钟，右为 SD、Wi-Fi、电池与电量，数值统一 18 号字，电池槽内宽 20 px。图标全部为生成的 alpha 图片（替代原 `statusbar` 字体符号），由 recolor 着色。SD 图标跟随平台上报的录制状态：变化时先上移滑出状态栏，在栏外换色，再回弹滑入；录制中蓝色闪烁，未录制为静止白色，快速往返以最后一次上报为准。状态栏、首页与设置页刷新只在值变化时调用 LVGL，空闲时不再周期性重绘。

| 页面 | 过渡 |
| --- | --- |
| Startup | 从顶部覆盖下落 |
| SystemLoading / Dialplate | 从底部覆盖上推；首页面板与按钮稍晚同向升起（仅开机首次进入播放，返回首页不重播） |
| WorkSettings | 横向推入 |
| RecordConfig / SaveConfig | 从底部覆盖进入 |
| SystemDash | 从顶部覆盖进入，电源面板淡入 |
| SystemInfos / StarMap | 纵向推入 |

所有页面切换统一 `style::kPageTransitionMs`（260 ms）、缓出曲线，Back 沿同一过渡反向退出。为在性能不足时保持流畅：

- **不用整页淡入**：整页透明度需要按块渲染到带透明通道的图层再逐像素混合，是 MCU 上最贵的切换；且 LVGL 8.3 对含全屏子对象的页面（SaveConfig 的背景层）在该图层中绘制错位，表现为切到关机页时一闪花屏（主机逐帧渲染复现，改为滑动后消失）。
- **创建时间不计入动画**：被弹出的页面会卸载，每次进入都要重新创建；LVGL 会把动画计时器上次运行以来的时间全部记到新动画上，创建耗时会让第一帧直接跳过一大段。`PageManager::switch_to()` 先创建页面，再 `lv_anim_refr_now()`，然后启动切换动画（有回归测试模拟 200 ms 的创建）。
- **预加载**：SystemLoading 期间（常在等主控）预先创建首页和关机页 SaveConfig；其余页面进入时创建——96 KB LVGL 池放不下所有页面常驻，全量预加载在主机测试中耗尽内存池。
- **减少叠加动画**：控件入场与首页入场只用位移；首页入场不再改坐标/高度（不触发重新布局）；屏幕对象关闭滚动条，滑动时不再画溢出滚动条。
- **SystemDash → SaveConfig**：长按完成时确认窗保持原样，切换结束（`did_disappear`）后再关闭，下层画面在滑动中不变化。

## 卫星数字布局

两组数字与斜杠按字体基线对齐，使用 LVGL flex 按实际位数紧凑居中，两侧保持 2 px 间隔。三位 NumberFlow 隐藏前导零但不留空位，消除原先 `% 100` 的回绕。有效 0 显示 0，无效数据为 `-- / --`。回归覆盖个位、两位、三位及混合组合，检查数字位、间距、居中、基线和容器边界。

## 验证

- 上游主机测试 **10/10**；ASan/UBSan **10/10**。新增 SD 图标动画状态机、无重启平台拒绝 Reboot、记录单击启停的断言。
- HC32 主机测试 **9/9**，包括两个显示产品的真实 AppPlatform 路径、请求发送/接收状态、状态栏 SD 图标跟随主控确认的录制状态、Wi-Fi、关机与内存余量。
- `x1pro/xbase` 的 Debug/Release 均构建通过，日志未发现编译警告；`x1` 不编译共享应用与 `Vendor/HC32/Display`，本轮 Debug/Release 为最新（无需重编）。
- 默认、X1Pro、XBase 三个模拟器构建通过，均通过 SDL dummy 启动及 SIGTERM 正常清理退出检查。
- 主机 LVGL 池峰值：X1Pro **31606 / 98304 B**，余量 **66698 B**；XBase **29434 / 98304 B**，余量 **68870 B**。主机为 64 位指针，此值不能当作实机测量。
- Release Flash：X1Pro **339788 B / 456 KB**，XBase **339364 B / 456 KB**（删除旧位图与状态栏字体后比上一轮约少 2.4 KB）；静态 RAM 均为 **169624 B / 188 KB**，其中包含 LVGL 静态池。
- 空闲重绘（主机渲染统计，2 s 内刷新像素折合整屏）：工作页 3.6→0.2、记录页 4.2→0.2 屏/秒，剩余为状态栏充电动画；首页只剩两张 54×44 状态卡的动效。

## 提交前复审

复审范围为上游公共服务、全部页面 Controller/Model/View，以及 HC32 `AppPlatform`、`DeviceBridge`、`StatusBridge`，重点检查请求校验、焦点、定时器与动画生命周期、导航与电源流程。

- 修复：首页卡片动效与图标重叠（LVGL 角度 0° 向右、顺时针，原“左右弧”实际画在天线上下）；平台无重启时服务层也拒绝 Reboot；设置页 200 ms 刷新与首页 1 Hz 设备快照造成的持续重绘（含聚焦按钮边框色误判）。
- 记录启停统一为单击（双击同样有效）；等待主控确认时按钮禁用，不重复发送。
- 26 个图标从矢量源重渲染，与提交的 alpha 数据逐字节相同。

## 剩余边界

- 未上板检查 AMOLED 帧率、屏幕遮挡和真实两键手感，也未改变主控协议。
- SaveConfig 仍使用既有固定准备时间，不能作为后端真实保存进度；本轮不改电源业务时序。
- 重新进入工作页/记录页时，等待中请求的 15 s 超时从进入时刻重新计算，只影响超时提示出现的时间。
- 同步前校验共享文件与记录的上游提交一致，保留原有 Dialplate/电台资源修改。上游新增资源注册沿用原文件 CRLF 行尾；按 CRLF 配置检查通过，默认空白检查会将这些 CR 字符报告为行尾空白。
