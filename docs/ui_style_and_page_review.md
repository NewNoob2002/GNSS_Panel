# 页面结构、视觉规则与验证

共享应用源码为 ATK_RK3506 `application/App`；修改先在上游提交，再同步到 HC32 `Simulator/App`。当前应用提交为 `a132dc5ac37aab2a56b6cb1cd2fec2f8a6d0fbda`；包含此前的菜单整合、业务反馈与聚焦修复。

## 当前职责与入口

```text
待机 Startup → 初始化 SystemLoading → 首页 Dialplate
                                      ├─ 工作配置 WorkSettings
                                      ├─ 记录管理 RecordConfig
                                      ├─ 设备信息 SystemInfos
                                      ├─ 系统 SystemDash
                                      │    ├─ 语言
                                      │    ├─ Wi-Fi（按产品能力）
                                      │    ├─ 电源 → 确认 → SaveConfig
                                      │    └─ 返回
                                      └─ 卫星区 → 卫星详情 StarMap（按产品能力）
```

| 页面 | 职责与本轮调整 |
| --- | --- |
| Dialplate | 快速查看工作状态并进入常用任务。四个入口以原 Device Info 三横线为视觉基准，统一原创白色 16×16 alpha 图标：工作参数、记录、信息列表、系统齿轮。移除底部焦点文字，按钮恢复 56×32；卫星区保持纯数值。录制中以红框提示，不伪装为直接停止按钮。 |
| WorkSettings | 选择电台移动站、电台基站、网络基站预设，再调整电台参数并显式应用。预设切换不直接下发命令。网络基站隐藏电台字段。 |
| RecordConfig | 显示记录状态、剩余空间、格式/间隔及启停。默认聚焦主操作，开始须提交、停止用选择；记录中和请求等待时锁定参数。XBase 显示固定参数，不再展示禁用的调整箭头。 |
| SystemInfos | 恢复全屏只读诊断，保留工作、定位、网络、电池、存储、系统六项。每次进入默认聚焦根页面，滚轮/方向键翻阅信息项，根页面或信息项点击即返回；不保留上次查看项、不显示新增浏览提示。 |
| SystemDash | 合并原系统菜单和设置子页，同屏提供语言、Wi-Fi、电源和返回。旧 SystemSettings 代码与路由已删除，无兼容别名。 |
| StarMap | 各星座数量详情，可见标题为 Satellites/Спутники，内部路由保留。 |
| Startup | 待机信息、电池、长按开机；开机由平台决定。 |
| SystemLoading | 品牌和初始化阶段，保留失败不中断启动、完成警告和平台步骤检查。 |
| SaveConfig | 用户关机准备与平台关机原因；电源确认默认取消，双击提交，平台关机不可取消。 |

页面按任务划分，工作、记录与只读信息继续独立；整合了价值较低的系统设置中间层，工作页焦点从原来 8 个减少为 5 个（网络基站 3 个），记录页从 6 个减少为 4 个（固定参数或记录中仅主操作与返回）。

## 工作预设和应用反馈

- 进入工作页时从设备快照读取预设、协议与信道，默认聚焦预设；选择在三种预设之间循环，协议/信道各自单击循环。
- 点击 Apply 才发送，提交动作也仅在聚焦 Apply 时有效。CUSTOM 信道用于电台预设时留页提示，网络基站不受此限制。
- 页面保持打开，反馈区分等待主控、请求已接收、拒绝、15 秒超时；等待期间不允许覆盖同类请求，但始终可以返回。
- 记录操作复用相同的反馈规则。未录制时单击不开始，Commit 才发起开始；录制时选择停止。重复提交不会覆盖正在等待的请求。
- 返回页面不取消已经发送的主控请求，超时也不清除平台请求；迟到的确认会更新为已接收。
- HC32 `DeviceBridge` 将 `work_pending`、`record_op || record_settings_pending` 发布为共享快照的等待状态。协议确认的是主控已读走请求，**不是物理操作已经完成**，因此文案使用 Request received，不显示 Apply succeeded。
- 模拟后端可同步接受并发布状态；真实平台可异步报告，页面兼容两种情况。等待定时器在离页及卸载时清理；语言更新不重建其他缓存页的焦点组。

## 视觉与动画

通用颜色集中在 `Simulator/App/Utils/PageStyle.h`。

| 语义 | 颜色 |
| --- | --- |
| 背景 / 面板 / 卡片 | `#101214` / `#202428` / `#181C20` |
| 边线 / 主文字 / 次文字 | `#414A52` / `#F2F4F5` / `#A4ADB5` |
| 焦点边框 / 焦点底色 / 按压底色 | `#FF931E` / `#34302A` / `#3A424A` |
| 正常、移动站、RX / 基准站、TX、连接 | `#28C76F` / `#3498DB` |
| 危险、失败 / 进度高亮 | `#D03C3B` / `#F6D062` |

星座分类色条、Logo、过温横幅继续使用各自的语义色。圆角沿用 8–12 px，焦点立即切换橙框，按压尺寸保留动画。Dialplate 已移除重复的边框颜色过渡，连续 100 次快速正反向切焦点回归检查只有当前控件显示橙框。

工作、记录、系统设置改为左侧图形主卡和右侧参数/操作卡，加入原生 16/32 px 图标、渐变、网络连接图形与状态点。控件每隔 40 ms 依次淡入并从下方 6 px 进入，数值变化时短淡入；只有主控等待或记录进行时状态点持续呼吸，离页和销毁时停止。正常状态不增加操作说明文字，错误、等待、确认等业务反馈保留。

上游 `tools/generate_ui_icons.py` 保存原创矢量路径并用已有 ImageMagick 生成 19 个原生尺寸 alpha 资源，包含像素数量、亮度与首页图标墨量自检。未引入外部图标下载依赖，固件运行时不放大首页图标。

| 页面 | 过渡 |
| --- | --- |
| Startup / SystemLoading / Dialplate | 280 / 360 / 320 ms 淡入；保留长按环、初始化阶段和首页控件依次展开 |
| WorkSettings | 300 ms 横向推入 |
| RecordConfig | 280 ms 从底部覆盖进入 |
| SystemDash | 280 ms 从顶部覆盖进入，电源面板淡入 |
| SystemInfos | 280 ms 纵向推入，详情区滚动 |
| StarMap | 280 ms 淡入，七列依次显现 |
| SaveConfig | 240 ms 淡入，品牌、说明与轨道依次进入 |

Back 沿同一过渡反向退出；不增加全屏动画缓存。

## 卫星数字布局

两组数字与斜杠按字体基线对齐，使用 LVGL flex 按实际位数紧凑居中，两侧保持 2 px 间隔。三位 NumberFlow 隐藏前导零但不留空位，消除原先 `% 100` 的回绕。有效 0 显示 0，无效数据为 `-- / --`。回归覆盖个位、两位、三位及混合组合，检查数字位、间距、居中、基线和容器边界。

## 剩余边界

- 未上板检查 AMOLED 帧率、屏幕遮挡和真实两键手感，也未改变主控协议。
- SaveConfig 仍使用既有固定准备时间，不能作为后端真实保存进度；本轮不改电源业务时序。
- 顶部 SD 图标的记录语义仍需与产品定义统一，HC32 StatusBridge 目前保留原有 `recording=false` 行为。
- 同步前校验共享文件与记录的上游提交一致，保留原有 Dialplate/电台资源修改。上游新增资源注册沿用原文件 CRLF 行尾；按 CRLF 配置检查通过，默认空白检查会将这些 CR 字符报告为行尾空白。
